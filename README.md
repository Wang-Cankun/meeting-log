# MeetingLog

MeetingLog is a personal macOS menu bar app that records all Mac audio or one application's audio, optionally includes a microphone and screen video, and turns each session into an archived transcript and evidence-bound summary.

## Start here

1. Run `scripts/build-app.sh` on macOS 26 or later.
2. Open `.build/MeetingLog.app`.
3. Open Settings to choose an archive root, OpenRouter model, and API key.
4. Grant microphone and screen-recording permissions when macOS asks.
